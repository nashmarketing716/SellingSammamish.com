# sellingsammamish.com

Website for Ericka Nash, a top real estate broker in Sammamish and neighborhood expert in Sahalee Estates, Timberline and Heritage Hills.

Static site published from the repo root by Netlify (see `netlify.toml`).

- `index.html`: home page
- `sahalee-estates/`, `timberline/`, `heritage-hills/`: neighborhood pages
- `styles.css`: shared styles
- `sitemap.xml`, `robots.txt`, `llms.txt`: search and AI discovery files

When the site moves to erickanash.com, update the domain in the canonical/og:url tags, sitemap.xml, robots.txt and llms.txt.
